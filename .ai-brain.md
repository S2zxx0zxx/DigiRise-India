## 1. Token-Efficiency Notes

## 2. Project Overview & Tech Stack
**DigiRise India** is a premium digital marketing agency website. 
- **Stack:** Pure HTML5, CSS3, Vanilla JavaScript. 
- **Dependencies:** ZERO. No React, Vue, jQuery, Tailwind, or build tools (Webpack/Vite). 
- **Deployment:** Vercel (Static hosting).
- **Architecture:** A monolithic single-page application (`index.html`) accompanied by a static multi-page blog architecture (`blog/`).

**CRITICAL RULE:** Do not introduce modern JS frameworks or build pipelines. All code must run natively in the browser without compilation.

## 6. Design System Reference
- **Theme:** Dark Mode (`[data-theme="dark"]`) by default. Light mode is supported via the FAB toggle.
- **Typography:** Space Grotesk (Headings), Plus Jakarta Sans (Body), VT323 (LED Brand Display).
- **Gold Accents:** `--gold` (`#f0a825`), `--gold-mid`, `--gold-deep`.
- **Glassmorphism:** Use `rgba(18,14,8,0.85)` with `backdrop-filter: blur(24px)`.
- **Monochrome Status Pills:** E.g., the `.island-status` header clock uses flat, border-radius styling with no glow, enforcing a clean professional look over excessive neon.

## 7. Data Flow Map
- **Pricing:** `packages` array (in `index.html`) → `renderPackages()` → `#pkgGrid`.
- **Industries:** `industries` array → `renderIndustries()` → `#industries-grid`.
- **Clients:** `pocClients` array → Tap Event on `.poc-phone` → Updates `.poc-screen` and `.poc-shot-link`.
- **Forms/WhatsApp:** Input fields → `encodeURIComponent()` → `window.open(wa.me/...)`. No external servers.

## 8. Cross-File Dependency Map
- **New Blog Post:** Add `blog/<post>.html` → Update `blog/blogs.json` → Update `blog/index.html` → Append text to `llms-full.txt` → Update `llms.txt` list → Add URL to `sitemap.xml` and `feed.xml`.
- **Price/Service Change:** Update UI state in `index.html` → Update `LocalBusiness`/`Offer` JSON-LD schema in `index.html` → Update facts in `llms.txt`.
- **Asset Changes:** If HTML, CSS, JS, or images change → Bump `CACHE_NAME` in `sw.js`.

## 9. Security & Privacy Notes
- **.ai-brain.md Privacy:** This file lives as a dotfile so Vercel ignores it. It is explicitly blocked in `robots.txt`. Do not link to it from any public HTML.
- **Secrets:** No hardcoded API keys are present. All contact forms route to WhatsApp using safe URI encoding to prevent XSS.
- **Tabnabbing:** All external links (`target="_blank"`) must use `rel="noopener"`.

## 10. Cache & Deployment Notes
- **Service Worker (`sw.js`):** Every deploy that alters cached files (HTML/CSS/JS) must bump the `CACHE_NAME` string in `sw.js` (e.g., from `v4` to `v5`). Otherwise, returning users will see broken/stale UI.
