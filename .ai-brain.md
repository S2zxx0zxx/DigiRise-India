## 2. Project Overview & Tech Stack
**DigiRise India** is a premium digital marketing agency website. 
- **Stack:** Pure HTML5, CSS3, Vanilla JavaScript. 
- **Dependencies:** ZERO. No React, Vue, jQuery, Tailwind, or build tools (Webpack/Vite). 
- **Deployment:** Vercel (Static hosting).
- **Architecture:** A monolithic single-page application (`index.html`) accompanied by a static multi-page blog architecture (`blog/`).

**CRITICAL RULE:** Do not introduce modern JS frameworks or build pipelines. All code must run natively in the browser without compilation.

## 11. Agent Update Protocols
1. **Always read this file first.**
2. **Video Uploads:** If asked to add/replace a video asset, verify it is a valid non-empty MP4. Ensure it has a poster image and update the corresponding `VideoObject` JSON-LD schema.
3. **Schema Integrity:** Do not break the nested JSON-LD structure in `index.html`. Use linters/validators if you modify the schema.
4. **Update this ledger:** If you fix a bug, log it in Section 4. If you add a file, map it in Section 3.
5. **PERMANENT PERFORMANCE RULE (added v3.8):** Before adding ANY new scroll listener, IntersectionObserver, `setInterval`, or infinite CSS animation (`animation:...infinite`), you MUST:
   - Check if the existing `_scrollCbs` orchestrator in `ios26.js` can be extended instead of creating a new `addEventListener('scroll', ...)`.
   - Check if an existing IntersectionObserver can be reused, or add your new observer to the `SECTIONS` array in the animation gate IIFE.
   - Check if your new infinite animation is included in the off-screen gate in the animation gate IIFE — if not, add its selector.
   - Never use `requestAnimationFrame(tick)` where `tick` calls itself unconditionally — always add a termination condition or a `document.visibilityState` guard.
   - Adding permanent `will-change` in CSS is FORBIDDEN — use the dynamic JS pattern (set on IO enter, remove on IO leave).
6. **PERMANENT ANIMATION RULE (added v5.1):** Before shipping any scroll-reveal, fade-in, or stagger-animation pattern, its `IntersectionObserver` `rootMargin`/`threshold` and total worst-case delay (transition duration + max stagger delay) must be explicitly reasoned through against fast-scroll behavior. Never use negative `rootMargin` for reveals; elements must pre-reveal before entering the visible viewport.
